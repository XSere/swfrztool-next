# swfrztool-gui

希沃冰点还原控制工具（重构版本），基于 C++17 + Win32 + Direct2D/DirectWrite 自绘界面，零第三方依赖，静态 CRT 编译。

## 功能说明与原理

### 1. 冰点配置
- **作用**：修改 `C:\ProgramData\SeewoFreezeKernelConfig\VolumeInfo.config` 中各卷的保护配置，重启后生效。
- **原理**：直接读写真实配置文件（使用 `FILE_FLAG_SEQUENTIAL_SCAN` 可以绕过驱动重定向），属于纯 R3 文件操作，**不依赖内核驱动是否加载成功**。
- **稳定性**：最高，推荐优先使用。

### 2. 配置伪装
- **作用**：修改 `redirect.config`，控制状态伪装（Filter）的卷保护显示。
- **原理**：首次使用时自动启用状态伪装（通过 `IOCTL_FLT_STATUS` 通知内核驱动），然后写入伪装配置文件。需要驱动已加载且冰点信息可用。
- **稳定性**：高，推荐优先使用。

### 3. 白名单管理
- **作用**：向指定卷的冰点白名单写入/清除文件、文件夹或扇区范围。
- **原理**：
  - **按文件**：计算文件数据簇、MFT 记录、父目录簇，合并为扇区范围后通过 `IOCTL_BMP_RANGES` 写入内核位图。
  - **按文件夹**：后台线程递归枚举文件夹，逐个文件计算扇区范围并写入，带进度显示。
  - **按扇区范围**：直接输入起始扇区和扇区数，通过 `IOCTL_BMP_RANGES` 写入。
- **路径校验**：输入路径必须与当前选中卷一致（如选 E 盘不能给 C 盘路径）。
- **稳定性**：高，推荐优先使用。

### 4. 保护状态\(不推荐\)
- **作用**：切换卷的实时保护状态（保护/未保护/绕过）。
- **原理**：通过 `IOCTL_VOL_PROT` 直接修改内核中的卷保护位图，立即生效，无需重启。
- **注意**：未启用保护的卷无法直接设为保护。

### 5. MJFUNC\(不推荐\)
- **作用**：设置磁盘驱动的分发例程（Major Function）钩子。
- **原理**：通过 `IOCTL_MJFUNC` 修改内核磁盘驱动的 IRP 处理函数表。
- **风险**：高风险操作，可能导致系统不稳定。

## 使用建议

**推荐只使用冰点配置、配置伪装、白名单管理**，它们最稳定且风险最低。保护状态、MJFUNC直接操作文件系统，可能导致蓝屏或数据损坏，请谨慎使用。

## 构建要求

- Visual Studio 2022/2026（MSVC 14.x）
- Windows SDK 10.0.22000+
- CMake 3.15+
- 静态 CRT（/MT），无需目标机器安装 VC++ 运行库

## 编译

```bash
cmake -B out/build/x64-Release -G Ninja -DCMAKE_BUILD_TYPE=RelWithDebInfo
cmake --build out/build/x64-Release --config RelWithDebInfo
```

生成的 `swfrztool-gui.exe` 会自动请求管理员权限。
